# Leo Home

Leo Home is the primary keypad interface. It shows the clock, network and SIM
status, notifications, shortcuts and a contextual card. The wallpaper, theme,
accent and the Home layout editor work together on the same screen.

| From | Key | Action |
| --- | --- | --- |
| Home | Left softkey | Open notifications |
| Home | OK with no selection | Open apps |
| Home | Up / Down | Quick settings / notifications |
| Home | Left / Right | Focus a shortcut or available card |
| Home | Right softkey | Open its assigned app, initially Contacts |
| Home | Dedicated Back | Clear the current selection |
| Home | Dedicated Menu | Open the universal Leo menu |
| Apps | Left softkey | Personalization, search, ordering and categories |
| Apps | `* / #` | Previous / next category in full mode |
| Apps list | Left / Right | Previous / next category in full mode |
| Apps | `1–9` / `0` | Select a slot / advance to the next page |
| Apps | OK / right softkey | Open the selected app / return Home |

Open **Menu → Options → Personalization** to change the accent, Home
indicators, shortcuts, wallpaper or menu layout. **Home editor** lets you
move, resize, rotate and hide individual elements using the D-pad and softkeys.
To change the right softkey, choose **Right softkey** in Personalization or
highlight an app and choose **Options → Assign to right softkey**.
The dedicated Menu key opens the global Leo menu when the Leo accessibility
service is running.

The modern layout saves to its own preferences. On first use it reads the
layout associated with the previously active shell. Legacy layout data stays
readable in backups.

The [RM-159 firmware extraction notes](N95-RM159-EXTRACTION.md) document the
original Symbian resources kept as a local reference.
